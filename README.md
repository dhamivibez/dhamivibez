## Local Development

Use Bun 1.4.4 or newer for its built-in TypeScript checker and formatter.

```sh
bun install
bun run dev
```

- `bun check` — type-check the project without writing files.
- `bun fmt` — format the project, including Tailwind CSS class sorting.
- `bun fmt --check` — check formatting without writing files.
- `bun run build` — build the portfolio.
- `bun run serve` — preview the build locally.

Formatting preferences live in `bunfig.toml`. There is no lint script for now, and Cloudflare Workers deployment is no longer configured.
